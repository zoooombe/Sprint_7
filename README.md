# Тестирование API Яндекс Самокат

Этот проект содержит автоматизированные тесты для API сервиса Яндекс Самокат.

## Структура проекта

- `tests/` - директория с тестами
  - `test_courier.py` - тесты для работы с курьерами
  - `test_order.py` - тесты для работы с заказами
- `helpers/` - вспомогательные классы
  - `api_client.py` - клиент для работы с API
- `utils/` - утилиты
  - `generators.py` - генераторы тестовых данных
- `requirements.txt` - зависимости проекта
